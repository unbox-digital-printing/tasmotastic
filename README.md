# TasmoTastic – Website

Dies ist die öffentliche Website von **TasmoTastic**.

TasmoTastic ist eine Android-App zur Verwaltung und Steuerung von Tasmota-basierten Smart-Home-Geräten im lokalen Netzwerk.

## Website

Die Website enthält:

- eine Kurzvorstellung von TasmoTastic
- die Datenschutzerklärung für die App.
